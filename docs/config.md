## 1. 書き方の共通ルール

| ルール | 内容 |
|---|---|
| 文字列はダブルクオート | 値が文字列なら、必ず `"…"` で囲みます（例：`name: "歌い手A"`）。囲んでいない文字列があると、実行時にエラーで止まります。キー名（`name:` など）、数値、`true` / `false` は囲みません。 |
| チャンネル・再生リストは名前とIDの組 | `{id: "…", name: "…"}` の形で書きます。判別に使うのは **id だけ** で、name は人が読むためのものです。 |
| 名前で探さない | チャンネルも再生リストも、名前で検索・照合することはありません。名前が YouTube 上の実際の名前と違う場合は、レポートの「名前の不一致」に表示されるだけです。 |
| システムが書き込むもの | 「新しく作った再生リストの id」と「昇格した曲」だけを、`config.yaml` に書き込みます。コメント・クオート・並び順は保たれます（[9章](#9-システムによる書き込み)）。 |
| 3分類の name は一意 | `top_favorites` / `favorites` / `occasional` の全項目を通して、`name` は重複できません（チャンネルを名前で指定するときの参照先になるため）。 |
| 省略 | 「既定」欄に値がある項目は省略できます。省略すると既定値になります。 |

## 2. 値の型

| 型 | 書き方 | 説明 |
|---|---|---|
| 文字列 | `"…"` | ダブルクオート必須。 |
| 文字列リスト | `["…", "…"]` | 空なら `[]`。 |
| 真偽値 | `true` / `false` | クオートしない。 |
| 数値 | `9000` | クオートしない。 |
| チャンネル | `{id: "UC…", name: "…"}` または `"3分類の name"` | オブジェクトで書く場合は **id・name ともに必須**です。id は `UC` で始まる24文字のチャンネルID。name は確認用で、判別には使いません。<br>文字列で書く場合は、`top_favorites` / `favorites` / `occasional` のどれかの項目の `name` を指定します。その項目の `channels`（本人・サブ・TOPIC）**すべて**を指します。**3分類の `channels` の中だけは、文字列では書けません**。 |
| チャンネルリスト | `- {id: "UC…", name: "…"}` や `- "3分類の name"` を並べる | 上のチャンネルのリスト。2つの書き方は混ぜられます（例：`published_by: ["作曲者B", {id: "UC…", name: "レーベルC"}]`）。 |
| 再生リスト | `{id: "PL…", name: "…"}` | **name は必須、id は任意**（`other.playlist` だけは id 必須）。id があればその再生リストを使います。id がなければ、name の名前で新しく作り、作ったIDを `config.yaml` のその場所に書き込みます。作成は、`config.yaml` を main に push した直後と、毎日の実行の最初に行います（[9章](#9-システムによる書き込み)）。 |
| 動画IDリスト | `["dQw4w9WgXcQ", …]` | 11文字の動画IDのリスト。 |

> チャンネルIDは、チャンネルページの「概要」→「チャンネルを共有」→「チャンネルIDをコピー」で取れます。再生リストIDは、再生リストのURLの `list=` の後ろの部分です。

## 3. トップレベル

| フィールド | 型 | 既定 | 説明 |
|---|---|---|---|
| `playlist_privacy` | 文字列 | `"private"` | 新しく作る再生リストの公開設定（`"private"` / `"unlisted"` / `"public"`）。 |
| `quota.daily_budget` | 数値 | `9000` | 1回の実行で使うAPIの上限（1日の上限は10000）。残りの1000は、`config.yaml` を変更したときの再生リスト作成（1つ50）などに使えます。 |
| `quota.write_reserve` | 数値 | `2000` | 書き込み（曲の追加）のために残しておく量。管理外の再生リストのバックアップ、新しく追加したチャンネルの全件取得、検索は、残りがこの量を下回りそうなら次回に回します。 |
| `playlists.unsorted` | 再生リスト | `{name: "未仕分け"}` | 「未仕分け」。システムは**追加だけ**を行い、削除は一切しません。 |
| `playlists.misc` | 再生リスト | `{name: "その他の曲"}` | 「その他の曲」。自分で振り分ける再生リストで、システムは追加しません（昇格の判定に使うだけ）。 |
| `music.categories` | 文字列リスト | `["10"]` | 曲とみなす YouTube カテゴリID（10 = 音楽）。 |
| `music.include_keywords` | 文字列リスト | `[]` | カテゴリが違っても、タイトルにこの語があれば曲とみなす。 |
| `music.exclude_keywords` | 文字列リスト | `[]` | タイトルにこの語があれば曲とみなさない。 |
| `music.min_seconds` | 数値 | `61` | これより短い動画は除外（ショート対策）。 |
| `music.max_seconds` | 数値 | `900` | これより長い動画は除外（配信アーカイブ・メドレー対策）。 |
| `matching.use_description` | 真偽値 | `true` | 関係曲・相手の判定で、概要欄も見るか。 |
| `dedupe.enabled` | 真偽値 | `true` | 重複除去（[7章](#7-振り分けの決まり方)）を行うか。 |
| `promotion.enabled` | 真偽値 | `true` | 「その他の曲」から「お気に入りの曲」への自動昇格を行うか。 |
| `promotion.min_versions` | 数値 | `5` | 昇格に必要な本家/カバーの数（同じ人の同じ音源は1と数える）。 |
| `promotion.ignore` | 文字列リスト | `[]` | 昇格させない曲名。昇格済みの曲を取り消すときもここに書きます。 |
| `ignore_video_ids` | 動画IDリスト | `[]` | どの再生リストにも自動で入れない動画。 |
| `ignore_playlists` | 再生リストのリスト（**id・name ともに必須**） | `[]` | 管理外にする再生リスト。バックアップも取りません。ここに書いた再生リストを、ほかの場所で使うことはできません。 |
| `top_favorites` | チャンネル項目のリスト | `[]` | 特にお気に入りのチャンネル。 |
| `favorites` | チャンネル項目のリスト | `[]` | お気に入りのチャンネル。 |
| `occasional` | チャンネル項目のリスト | `[]` | たまに聴くチャンネル。 |
| `songs` | 曲項目のリスト | `[]` | お気に入りの曲。 |

**オフボーカル音源：** Instrumental・Inst.・Off Vocal・オフボーカル・カラオケ・Backing Track を含む動画は、既定ではどの再生リストにも入れません。再生リストごとに `include_off_vocal: true` を書くと、**通常版（ボーカルあり）がない曲に限って**オフボーカルを入れます（[7章](#7-振り分けの決まり方)）。

## 4. チャンネル項目（top_favorites / favorites / occasional）

3分類とも書けるフィールドは同じです。違うのは、○○チャンネルが「自動」か「判断」かの既定だけです。「判断」は、候補を「未仕分け」に仮保存し、人が振り分けることを指します。

| フィールド | 型 | 必須 | top | fav | occ | 説明 |
|---|---|---|---|---|---|---|
| `name` | 文字列 | ○ | ○ | ○ | ○ | 表示用の名前。判別には使いません。 |
| `channels` | チャンネルリスト | ○ | ○ | ○ | ○ | この人のチャンネル（本人・サブ・TOPIC）。ここに並べたチャンネルは**同一人物**として扱い、重複除去もこのまとまりで行います。 |
| `playlist` | 再生リスト | | ○ | ○ | ○ | 「○○チャンネル」。`channels` が公開した曲が入ります。書かなければ作りません。 |
| `auto` | 真偽値 | | 既定 `true` | 既定 `false` | 既定 `false` | `playlist` を自動にするか（`false` なら判断）。 |
| `include_off_vocal` | 真偽値 | | ○ | ○ | ○ | `true` なら、通常版がない曲に限り `playlist` にオフボーカル音源を入れる（既定 `false`）。 |
| `include_video_ids` | 動画IDリスト | | ○ | ○ | ○ | `playlist` に必ず入れる動画。 |
| `exclude_video_ids` | 動画IDリスト | | ○ | ○ | ○ | `playlist` に入れない動画。 |
| `other` | その他○○の設定 | | ○ | ○ | ○ | 「その他○○」。下の表を参照。 |
| `aliases` | 文字列リスト | | ○ | ○ | ○ | 名前でも関係曲を探す。同名の別人が混ざるおそれがあるため、**名前だけで見つかった曲は、自動の再生リストでも必ず「未仕分け」に入れて確認**します。`published_by` のある `specials` では、`mention_aliases` がないときの代わりにも使います。 |
| `specials` | 特別再生リストのリスト | | ○ | ○ | ○ | [5章](#5-特別再生リストspecials)。 |
| `search` | 真偽値 | | ○ | × | × | `true` なら、監視していないチャンネルの関係曲も毎日検索します（APIを1回100消費）。 |
| `search_query` | 文字列 | | ○ | × | × | 検索に使う語（既定は `name`）。結果は @ハンドル/チャンネルID（または `aliases`）で確認できたものだけ使います。 |

### other（その他○○）

「その他○○」には、関係曲（下の用語を参照）が入ります。特別再生リストに入った曲は除きます。**自動では追加せず、候補を必ず「未仕分け」に仮保存します**（3分類とも同じ）。

| フィールド | 型 | 必須 | 既定 | 説明 |
|---|---|---|---|---|
| `other.playlist` | 再生リスト（**id 必須**） | ○ | | 「その他○○」の再生リスト。id があるときだけ扱います（システムが新しく作ることはありません）。 |
| `other.include_off_vocal` | 真偽値 | | `false` | `true` なら、通常版がない曲に限りオフボーカル音源も候補にする。 |
| `other.exclude_keywords` | 文字列リスト | | `[]` | タイトルにこの語がある曲は候補にしない。 |
| `other.include_video_ids` | 動画IDリスト | | `[]` | 必ず入れる動画（手動の指定なので、直接追加します）。 |
| `other.exclude_video_ids` | 動画IDリスト | | `[]` | 候補にしない動画。 |

**用語**
- **本人名義の曲**：`channels` のどれかが公開した曲。
- **関係曲**：`channels` 以外のチャンネルが公開した曲のうち、タイトルか概要欄に、`channels` のどれかの **@ハンドル** か **チャンネルID（URL）** が書かれているもの。@ハンドルは、チャンネルIDから自動で取得します。
- **名前だけの関係曲**：`aliases` の名前だけで見つかった曲。常に「判断」扱いになります。

## 5. 特別再生リスト（specials）

特別再生リストは、チャンネル項目（以下「この人」）の中に書きます。**対象範囲のうち、書いた条件をすべて満たす曲**が入ります。特別再生リストに入った曲は、同じ項目の「その他○○」からは除かれます。

| フィールド | 型 | 必須 | 既定 | 説明 |
|---|---|---|---|---|
| `playlist` | 再生リスト | ○ | | 特別再生リスト。 |
| `published_by` | チャンネルリスト | | なし | 公開したチャンネル。書くと、**対象範囲がこのチャンネルの動画だけ**になります（下の表）。 |
| `mentions` | チャンネルリスト | | なし（`published_by` があるときは「この人」の `channels`） | タイトル・概要欄に @ハンドル/チャンネルID が書かれている相手。ここで確認できた動画は自動で追加します。 |
| `mention_aliases` | 文字列リスト | | なし（`published_by` があるときは「この人」の `aliases`） | 相手を名前で探す。**名前だけで一致した動画は、必ず「未仕分け」で確認します**。 |
| `keywords` | 文字列リスト | | 制限なし | タイトルに含まれる語。 |
| `exclude_keywords` | 文字列リスト | | なし | タイトルにこの語があれば除外。 |
| `include_off_vocal` | 真偽値 | | `false` | `true` なら、通常版がない曲に限りオフボーカル音源を入れる。 |
| `require_related` | 真偽値 | | `true` | `false` にすると、「この人」との関係を確認しません。 |
| `auto` | 真偽値 | | `true` | `false` にすると判断（「未仕分け」経由）にします。 |
| `include_video_ids` | 動画IDリスト | | `[]` | 必ず入れる動画。 |
| `exclude_video_ids` | 動画IDリスト | | `[]` | 入れない動画。 |

### 対象範囲と関係の確認

| 場合 | 対象範囲 | 「この人」との関係の確認 |
|---|---|---|
| 場合 | 対象範囲 | 自動で追加する動画 | 「未仕分け」で確認する動画 |
|---|---|---|---|
| `published_by` なし | この人の曲（本人名義＋関係曲＋名前だけの関係曲） | 本人名義・関係曲のうち、`mentions` の相手の @ハンドル/チャンネルID があるもの（`mentions` / `mention_aliases` がなければすべて） | 名前だけの関係曲、`mention_aliases` の名前だけで一致したもの |
| `published_by` あり・`mentions` なし | `published_by` の動画**だけ**（この人のチャンネルは、`published_by` に書いたときだけ含む） | この人のチャンネルの動画、この人の `channels` の @ハンドル/チャンネルID があるもの | `mention_aliases`（なければこの人の `aliases`）の名前だけで一致したもの |
| `published_by` あり・`mentions` あり | `published_by` の動画**だけ** | `mentions` の相手の @ハンドル/チャンネルID があるもの | `mention_aliases`（なければこの人の `aliases`）の名前だけで一致したもの |
| `require_related: false` | `published_by` の動画（なければ監視中の全動画） | `mentions` / `mention_aliases` がなければすべて。あれば `mentions` で確認できたもの | `mention_aliases` の名前だけで一致したもの |

まとめると、**チャンネル（本人のチャンネル、@ハンドル、チャンネルID）で確認できた動画は自動**、**名前（`aliases` / `mention_aliases`）だけで見つかった動画は「未仕分け」**です。`specials[].auto: false` にすると、確認できた動画も「未仕分け」経由になります。

### 条件の組み合わせ（AND / OR）

```
入る曲 ＝ 対象範囲
        ∩ ［関係の確認（上の表）：mentions のどれかが書かれている（→自動）  または  mention_aliases のどれかが書かれている（→未仕分け）］
        ∩ ［タイトルに keywords のどれかを含む］
        − ［タイトルに exclude_keywords のどれかを含む］
        ＋ include_video_ids − exclude_video_ids
```

- **フィールドどうしは AND**：`published_by` と `keywords` の両方を書けば、両方を満たす曲だけが入ります。
- **1つのフィールドの中は OR**：`keywords: ["self cover", "セルフカバー"]` は、どちらかを含めば該当します。`published_by: ["作曲者B", "作曲者C"]` は、どちらかが公開した曲です。
- **`mentions` と `mention_aliases` は1つの条件**：この2つの間だけは OR です。
- **書かなかった条件は制限なし**：`keywords` などを何も書かなければ、対象範囲すべてが入ります。
- **名前だけの一致**：`aliases` / `mention_aliases` の名前だけで見つかった動画は、条件を満たしても「未仕分け」で確認します。

### 例

| やりたいこと | 書き方 |
|---|---|
| 作曲者Bが公開した、歌い手Aがボーカルの曲（歌い手Aの項目に書く） | `published_by: ["作曲者B"]` |
| 作曲者B本人のセルフカバー（作曲者Bの項目に書く） | `published_by: ["作曲者B"]`、`keywords: ["self cover", "セルフカバー"]` |
| 歌い手Dと歌い手Eのコラボ（歌い手Dの項目に書く） | `mentions: ["歌い手E"]`、`mention_aliases: ["歌い手E"]` |
| 歌い手Aと作曲者Bの両方の曲で、Aが関わるもの（歌い手Aの項目に書く） | `published_by: ["歌い手A", "作曲者B"]` |

## 6. お気に入りの曲（songs）

公式チャンネルと、3分類のチャンネルによるカバーを、曲名の再生リストに自動で集めます。

| フィールド | 型 | 必須 | 既定 | 説明 |
|---|---|---|---|---|
| `name` | 文字列 | ○ | | 曲名（表示用。`aliases` がなければ照合にも使う）。 |
| `playlist` | 再生リスト | | `{name: <name>}` | 曲の再生リスト。 |
| `aliases` | 文字列リスト | | `[name]` | 動画タイトルに含まれていれば該当（全角半角・大小文字・記号は無視）。 |
| `official_channels` | チャンネルリスト | | `[]` | 本家のチャンネル。3分類に入っていなくても、本家として集めます。 |
| `exclude_keywords` | 文字列リスト | | `[]` | 似た名前の別曲を除外。 |
| `include_off_vocal` | 真偽値 | | `false` | `true` なら、通常版がない曲に限りオフボーカル音源を入れる。 |
| `promoted_at` / `promoted_versions` | 文字列 / 数値 | | | 自動昇格したときにシステムが書き込む記録（動作には影響しません）。 |
| `include_video_ids` / `exclude_video_ids` | 動画IDリスト | | `[]` | 手動で入れる/入れない動画。 |

対象になるチャンネルは、`official_channels`、`top_favorites`、`favorites`、`occasional` のどれかに書いたチャンネルだけです。

## 7. 振り分けの決まり方

### 自動と判断

| 再生リスト | top | fav | occ |
|---|---|---|---|
| ○○チャンネル（`playlist`） | 自動 | 判断 | 判断 |
| その他○○（`other`） | 判断 | 判断 | 判断 |
| 特別再生リスト（`specials`） | 自動 | 自動 | 自動 |
| お気に入りの曲（`songs`） | 自動 | 自動 | 自動 |

○○チャンネルは `auto`、特別再生リストは `specials[].auto` で変えられます。「その他○○」は常に判断です。

### 「未仕分け」に入る曲（新しく公開された曲だけ）
1. 「判断」の再生リストの候補になった曲
2. `aliases` / `mention_aliases` の名前だけで見つかった曲（確認のため。自動の再生リストには入れません）
3. `favorites` / `occasional` のチャンネルが公開した曲のうち、どの自動の再生リストにも入らなかった曲（オフボーカル音源は除く）

ただし、次の曲は入れません。
- すでにどれかの管理対象の再生リストに入っている曲
- 一度「未仕分け」に入れた後、自分で消した曲

チャンネルを新しく設定に追加したときは、そのチャンネルの過去の曲を自動の再生リストには入れますが、「未仕分け」には入れません。システムは「未仕分け」から曲を消さないので、振り分け終わった曲は自分で消してください。

### 重複除去
1つの項目の `channels` に並べたチャンネルは同一人物として扱います。同一人物の動画で「曲名＋バージョン」が同じものは、1本だけを選びます。
- **選ぶ順番：** MV → 通常の動画 → TOPIC音源 → 本チャンネルのオフボーカル → TOPICのオフボーカル音源（同じ順位なら、公開日が古い方）。
- **バージョン：** タイトルの Remix / Ver. / Acoustic / Live / Self Cover / Piano などで区別します。Remix は、誰のRemixかも区別します。
- **オフボーカル：** オフボーカルはバージョンとしては扱わず、通常版と同じ曲とみなします。そのため、同じ人・同じ曲・同じバージョンの通常版が1本でもあれば、オフボーカルは入りません。通常版がない場合に限り、`include_off_vocal: true` の再生リストにオフボーカルが入ります。
  - 例：「曲 MV」があれば「曲 (Off Vocal)」は入らない。「曲 (Remix)」がなければ「曲 (Remix) [Off Vocal]」は入る。
  - 通常版があるかどうかは、その再生リストの条件に関係なく、監視している全動画で判定します（例：`keywords: ["off vocal"]` の特別再生リストでも、通常版がある曲は入りません）。
- **すでに入っている重複：** 自動では消しません。レポートの「重複の可能性」に表示します。

### 処理の軽さ
動画数が多くても動くように、次のようにしています。
- 動画ごとの正規化した文字列・曲名・概要欄の @ハンドル/チャンネルIDは、実行ごとに1回だけ計算します。
- チャンネル別・参照先別の逆引き表と、タイトルの2文字索引を作り、全件を走査せずに引きます。
- キーワードは、1本の正規表現にまとめて使い回します。
- 5万件の動画・数百項目の設定で、振り分けの計算は数秒程度です。

## 8. 整合性チェックと整形

APIを使わずに `config.yaml` を確認・整形するスクリプトがあります。

```bash
python -m ytpl.check            # config.yaml を確認（エラーがあれば終了コード 1）
python -m ytpl.check --fix      # 整形してから確認（ファイルを書き換える）
python -m ytpl.check other.yaml # ほかのファイルを確認
```

**整形（`--fix`）の内容**（何度実行しても同じ結果になります）
1. ダブルクオートのない文字列値に、ダブルクオートを付ける
2. インデント幅をファイル全体でそろえる
3. `top_favorites` / `favorites` / `occasional` の各項目を、`name` の辞書順に並べ替える（全角半角・大文字小文字は区別しない）

並べ替えでは、項目の**直前にあるコメント・空行**と、項目の中のコメントを、その項目と一緒に動かします。セクションの末尾にある行頭のコメント（次のセクションの見出し代わりのコメントなど）は、その場所に残ります。`songs` や、項目の中のリスト（`channels` など）の順番は変えません。

| 種類 | 内容 |
|---|---|
| エラー（実行も止まる） | YAMLの文法、ダブルクオートのない文字列、必須フィールドの不足、ID の形式、3分類の name の重複、存在しない name の指定、`channels` での名前指定、廃止されたフィールド |
| 警告（実行は続く） | 同じチャンネルが複数の項目にある、同じ再生リストIDが複数の場所にある、条件のない `require_related: false`、整形されていない |

- **コミット前に自動で確認する：** `git config core.hooksPath .githooks` を1回実行すると、`config.yaml` をコミットするたびに確認され、エラーがあればコミットが中止されます（`git commit --no-verify` で飛ばせます）。整形されていないだけなら、警告を出してコミットは通します。
- **GitHub上で直接編集した場合：** ワークフロー `check-config` が確認します。

## 9. システムによる書き込み

### config.yaml
システムが `config.yaml` に書き込むのは、次の2つだけです。

| 書き込むもの | 場所 | タイミング |
|---|---|---|
| 新しく作った再生リストの id | その再生リスト指定（例：`playlist: {name: "…"}` → `playlist: {id: "PL…", name: "…"}`） | `config.yaml` を main に push した直後（作成だけを行う実行）と、毎日の実行の最初。読み取りや曲の追加より先に作るので、すぐに手で仕分けを始められます |
| 昇格した曲 | `songs` の末尾に、`name` / `playlist` / `aliases` / `promoted_at` / `promoted_versions` を追加 | 「その他の曲」から昇格したとき（再生リストは、その曲を追加するときに作成） |

- **二重作成の防止：** 作成したのに id を書き戻せなかった場合（push の失敗など）、次の実行では、このツールが作った同じ名前の再生リスト（`config.yaml` からまだ参照されていないもの）を使い、新しくは作りません。

- **ライブラリ：** 書き込みには ruamel.yaml の round-trip 機能を使います。**コメント（行頭・行末・項目内）、ダブルクオート、キーの並び順、`{…}` / `[…]` の書き方は、そのまま保たれます**。
- **インデント：** インデント幅はファイルから推定し、ファイル全体をその幅にそろえて書き出します。場所によって幅を変えている場合だけ、書き込み時に統一されます。
- **ドライラン：** ドライランでは何も書き込みません。
- **手で編集していた場合：** 実行中に手で編集・pushしていても、ワークフローは最新の変更を取り込んでから push します。同じ行を両方で変えた場合だけ、push が失敗します。

### 手元で YouTube の状態を反映する（pull_config）

YouTube上の今の状態を、手元の `config.yaml` に反映するコマンドです。読み取りだけで、APIの使用量は数ユニットです。

```bash
python -m ytpl.pull_config                  # 変更内容を表示し、config.yaml を更新
python -m ytpl.pull_config --dry-run        # 表示だけ
python -m ytpl.pull_config --channel-names  # {id, name} で書いたチャンネルの name も更新
```

| 内容 | config.yaml への反映 |
|---|---|
| 再生リストの `name` を、YouTube上の今のタイトルに更新（id で照合） | 書き換える |
| YouTube上にない再生リスト・チャンネル | 警告だけ（変えない） |
| YouTube上にあるが、`config.yaml` にも `ignore_playlists` にもない再生リスト | `ignore_playlists` の末尾に `# 要確認` 付きで追加（以後は無視される）。管理したい場合は、正しい場所に移してください |
| `{id, name}` で書いたチャンネルの `name` | `--channel-names` のときだけ、今のチャンネル名に書き換える |
| 3分類の項目の `name`（利用者が付ける識別名） | 変えない |

書き換えは毎日の実行と同じく、コメント・クオート・並び順を保ちます。実行前に `git pull` し、実行後は `git diff` で確認してからコミットしてください。

### data/ と reports/

| ファイル | 内容 |
|---|---|
| `data/playlists/*.yaml` | 各再生リストの中身の台帳（バックアップ） |
| `data/catalog/*.yaml` | 監視チャンネルの動画情報 |
| `data/state.yaml` | @ハンドルのキャッシュ、最終実行日時など |
| `data/mix/index.json` | オリジナルミックスリスト用の索引（管理対象の再生リストの曲。「未仕分け」と `ignore_playlists` は除く）。Cloudflare Worker が読む |
| `reports/latest.md` | 最新の実行レポート |
| `reports/latest-create.md` | `config.yaml` の push で行った、作成だけの実行のレポート |

## 10. 廃止されたフィールド

次のフィールドが残っていると、エラーで止まります。

| フィールド | 代わり |
|---|---|
| `combos` | 各チャンネル項目の `specials` |
| `titles` | 各再生リストを `{id, name}` で直接書く |
| `channel_ids` / `official_channel_ids` / `partner_*` / `playlist_id` 系 | `channels` / `official_channels` / `mentions` / `{id, name}` の再生リスト |
| `other_playlist` / `other_playlist_id` / `other: true` | `other.playlist`（id の有無で扱うかが決まる） |
| `other_include_video_ids` / `other_exclude_video_ids` / `other_exclude_keywords` | `other.include_video_ids` / `other.exclude_video_ids` / `other.exclude_keywords` |
| `other_auto` | 廃止（「その他○○」は常に判断） |
| `unsorted.auto_remove_when_sorted` | 廃止（「未仕分け」からは削除しない） |
